## 四 · 规则升级建议

### 4.1 MEDIA_TIERS 扩充（第 3 批次提议）

score-candidates.js 的 MEDIA_TIERS 列表仅含 6 个域名（36kr/ifanr/ithome/theverge/wired/engadget），导致大部分 T1/T2 信源被标记为 "unknown"（0 bonus）。建议扩充：

```javascript
const MEDIA_TIERS = [
  { tier: "tier1_media", names: ["36kr.com", "ifanr.com", "ithome.com", "theverge.com", "wired.com", "engadget.com", "gizmochina.com", "thetechoutlook.com", "wemedia.it", "rtings.com", "ixbt.com", "notebookcheck.net", "hypebeast.com"] },
  { tier: "tier2_vertical", names: ["chongdiantou.com", "52audio.com", "dronedj.com", "otticasm.com", "shokz.com.cn", "about.fb.com"] }
];
```

预期影响：信源识别率从 ~20% 提升至 ~70%，sourceBonus 从 0 提升至 8（T1）或 5（T2），总分平均提升 5-8 分。

### 4.2 NEGATIVE_TERMS 优化

"续航提升" 作为 NEGATIVE_TERM 对 Framework 产品惩罚过重。续航提升可以是设计变化的结果（如更高效芯片架构），不一定是纯 spec bump。建议将 "续航提升" 降级为 0.5 权重惩罚而非全量 12 分。

### 4.3 G3.2 连续 3 批次无候选通过

recognition 和 cmfInnovation 维度仍为最常见短板。SIGNAL_RULES 中 recognition 的 terms（家族化/设计语言/glyph/iconic/signature/辨识度/去logo/视觉系统）在搜索结果摘要中命中率低。建议：
- 在提取阶段主动从信源页面提取品牌设计语言描述
- 或降低 recognition 维度的 SIGNAL_RULES weight 从 2 降至 1，减少该维度对总分的稀释
